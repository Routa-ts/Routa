My recommendation: keep Biome if speed is the reason to switch

Formatting and syntax lint are faster with Biome on this repository. Vite Task saves about 40 ms on a warm build lookup, while vp pack adds about 120 ms to an uncached package build. The full gate with cold task caches changes by +0.12 s, or +0.6%, in three runs per side. These samples do not establish a general speed advantage.

I would keep the vp command interface, preserve the test-coverage fix, and retain Biome formatting and syntax lint for performance. Broader adoption should be a deliberate choice for coordinated tooling and type-aware rules, with the memory and maintenance tradeoffs below. The branch remains the measured migration candidate.
