Cache package compilation and execute validation

Adopted

Before

Turbo cached builds, type checks, and tests. The recorded baseline verification reused all 18 Turbo task results.

After

Vite Task replaces Turbo. One bounded compilation task caches the three package outputs with explicit source/config/manifest/lockfile inputs. Tests and other package scripts are uncached.

Evidence. All four cache scenarios pass: warm hit, deleted-output restoration, source-change miss, and conservative rebuild after reverting the edit. Restoration reproduces all 19 files byte for byte, including executable modes.

What remains experimental or outside this migration

Compiler diagnostics in Oxlint and TypeScript 7 declaration generation through tsdown are experimental. Explicit TypeScript checks and packed-consumer tests remain required.

Native lint still emits advisory warnings. Astro retains its existing missing-i18n/404 content warnings. No failed check is treated as a pass.

Coverage reporting, browser testing, hooks, remote caching, automatic export generation, and a Vite-based application runtime were not adopted. They have no compatibility claim in this report. pnpm, Changesets, Astro, tsx, Routa's runtime TypeScript analysis, and scoped Biome checks remain.
