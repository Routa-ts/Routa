# Source-declared native HTTP interoperability

Routa V1 will support independent native Web Request input and native Web Response output on ordinary source-declared operations so applications can reuse standard HTTP handlers without recreating their transport behavior. Explicit paths, middleware, byte limits, cancellation, response ownership and resource lifetimes remain in the shared pipeline, while undeclared payload, status and media facts remain unknown in types, metadata and OpenAPI. This extends source-authoritative contracts with explicit opaque facts rather than introducing provider-specific runtime integrations; implementation remains pending.

Native responses own ordinary headers and can contribute cookies to the shared normalized response plan without declaring each cookie in advance. Routa validates and coalesces matching framework-owned header values and rejects conflicts before commitment; this native-only exception preserves ordinary declared producer exclusivity. The native response descriptor is Routa's only raw escape hatch: the earlier fixed-contract raw response is merged into it as optional declared status and media facts, and its streaming mode follows ADR-0008. Applications retain upstream configuration and authentication policy, including the separate decision about credential acquisition and recovery.
