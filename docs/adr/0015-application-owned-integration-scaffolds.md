# Application-owned integration scaffolds

Routa V1 will provide one `routa add <recipe>` workflow for Better Auth, Pino, OpenTelemetry, Redis and Vitest, starting with existing projects and generating editable application code through public Routa APIs and direct upstream dependencies. This generation-time convenience may create ordinary services, routes and protection middleware, while preserving optional wiring and application ownership rather than introducing runtime integration packages or privileged provider hooks. Installation uses an exact redacted source/configuration preview and bounded edits, identical reruns are no-ops, conflicts stop, and database execution requires separate explicit authorization; generated code is immediately application-owned and implementation remains pending.
